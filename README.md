# Distance-Calculator-Program

## Description
Converts Distance in kilometers into Miles

## How to Run
1. Open the program file in VS Code, Replit, or Google Colab.
2. Run the program
3. Enter the distance in kilometers
4. See the converted distance as displayed on the screen

## Input Needed
Distance in Kilometers

## Sample Output
Enter Distance in kilometers: 67
Distance in miles: 41.631857000000004
